# ✈️ Wingspan – Flight Booking System

A MERN stack web app for searching flights, booking tickets and managing trips.

🌐 **Live site:** https://flight-management-sysem-rmhr.vercel.app

## ✨ Features
- 🔍 Search flights by city or country, with date, passengers and class
- 🔐 Sign up, log in and log out (JWT authentication)
- 📧 Forgot / reset password through an emailed link
- 🎫 Book flights, view booking confirmation and travel history
- 👤 Profile settings (name, password, dark mode, notifications)
- 🤖 Trip Assistant chat widget
- 📱 Responsive design

## 🛠️ Tech Stack
| Part | Technology |
|------|------------|
| 🎨 Frontend | React (Vite), React Router, Axios |
| ⚙️ Backend | Node.js, Express |
| 🗄️ Database | MongoDB Atlas, Mongoose |
| 🔑 Auth | JWT, bcryptjs |
| ✉️ Email | Brevo API |
| ☁️ Hosting | Vercel |



## 🚀 Deployment
Frontend and backend are deployed as two separate Vercel projects.
